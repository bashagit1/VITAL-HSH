# HSH Vital Signs Monitoring App

This is a Streamlit-based application for monitoring patient vitals in the HSH Nursing Home.

## Features
- Enter and save patient vitals (BP, pulse, SpO₂, temperature, glucose).
- View patient history with filtering and exporting options.
- Generate monthly reports for patients.
- Register new staff members (admin-only).
- Real-time email alerts for critical values.
